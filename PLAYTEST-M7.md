# Beam Carry physical playtest - about 5-10 minutes

Open https://break-time-9n1k.onrender.com/ on laptop and iPhone after the verified deployment. Refresh both. Confirm the Milestone 7 build label; /health must report protocol 16. If it still reports 15, the accepted baseline is still live and the new course is not being tested.

1. Choose Beam Carry, create on laptop and join its code on iPhone. Check portrait and landscape: controls stay readable, the joystick and ACTION are reachable, and neither blocks the worker.
2. Start. Grab the assigned end on each device. Both ends should rise and both devices should show the same team. Move together north through the doorway. Release the joystick: the worker should stop without sticking. Release/regrab once.
3. Continue past the doorway, stop near the back rail and coordinate a right turn around the column. Follow the yellow corridor. Pause before each moving load, wait for clearance and carry past it. Confirm both devices see the same load movement and blocked feedback. No teleport, persistent clipping, or severe stutter.
4. Enter the green zone with the whole beam and keep both ends held while stopped. Confirm one team delivery, place and identical frozen finish time on both screens. Host restart should clear the delivery and restore both assigned ends.
5. During another run, reload the iPhone. It should recover the same worker and team; grab again. Check the existing reconnect and host-transfer behavior if time permits.
6. If four devices are available, repeat with two pairs: each has its own beam, other teams cannot grab yours, first delivery stays frozen while the second continues. Automated 2/4/6/8-client checks supplement this step.
7. Return to lobby and run the default three-race Wheelbarrow Championship. Confirm the four menu tiles, material cards, centered countdown, course transitions and final totals still behave as in the accepted protocol 15 build.

Report: laptop/browser, iPhone/browser, pass/fail per step, touch delay, stuck inputs, visible clipping and any error text. Physical-device acceptance is pending until the user reports results; screenshots and automated tests are not a physical playtest.
